What the model predicts

The U-Net predicts a 48×48 noise field. At each step, the sampler uses it to update the pixel values toward the requested character.

Why the stroke weight changes

The training fonts varied in size and line weight. A seed changes the initial and per-step noise, and the class label has no separate size or weight control.

Image representation

Diffusion runs on a grayscale pixel array, not explicit pen strokes. The browser enlarges each independent sample for viewing.
